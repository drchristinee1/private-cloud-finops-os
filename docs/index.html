Architecture

How the model works

1. Cost Pools

Infrastructure, storage, virtualization, labor, and platform overhead are collected into cost pools.

2. Supply Units

Capacity is translated into units such as vCPU-hours, GB RAM-hours, and TB storage.

3. Rate Card

Unit rates are computed so private cloud services can be priced internally with consistency.

4. Allocation Logic

Usage data is mapped to business teams or applications for showback or chargeback.

5. Budget Comparison

Allocated costs are compared to team budgets to support governance and decision-making.

GitHub Pages

How to publish this from your repo

  1. Create a folder named docs in your GitHub repository.
  2. Upload these files into the docs folder.
  3. In GitHub, go to Settings → Pages.
  4. Under Build and deployment, choose Deploy from a branch.
  5. Select your branch and set the folder to /docs.
  6. Save, then wait for GitHub to publish your site URL.

You can later connect this demo page back to your Python repo outputs, screenshots, or exported JSON artifacts.
