GitHub Pages How to publish this from your repo 1 Create a folder named docs in your GitHub repository. 2 Upload these files into the docs folder. 3 In GitHub, go to Settings → Pages. 4 Under Build and deployment, choose Deploy from a branch. 5 Select your branch and set the folder to /docs. 6 Save, then wait for GitHub to publish your site URL.
